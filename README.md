# AZ-RI HUD Environmental Review Worksheet

Single-file HTML form for HUD CEST / EA environmental reviews under
24 CFR Part 50 / Part 58. Mirrors HEROS section numbering and instructions.

## Usage
Open AZRI_HUD_ER_Form.html in Chrome. Use Chrome's "Install as app"
to pin it to the Dock.

## Iteration
New versions come from Claude. Drop the new file in, commit, push.
